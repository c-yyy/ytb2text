视频转文字V2T
v0.3.0
关于隐私与成本

Whisper 模型在你的本机浏览器里跑，音频不会上传到任何服务器， 也不需要填 API Key —— 运行过程0 调用成本。

怎么用

  1. 打开任意 YouTube 视频页，「分享 / 保存 / 下载」那一行会多出一个「转文字」按钮。
  2. 点它打开面板 → 点「开始转写」。音频是直接取下来的，不需要录制。
  3. 等进度条走完，结果可直接复制或导出 TXT / SRT / VTT。

说明

  • 目前只在 YouTube 上出现入口；其它页面不会有任何浮窗。
  • 首次转录会下载一次模型（Base 约 75MB），之后由浏览器缓存，完全离线可跑。
  • 有独显时自动走 WebGPU，接近实时；纯 CPU 下会慢一些。
  • 视频自带字幕时，面板里会出现「直接取字幕」，不用跑模型。
  • 音频是整条下载后解码的，比实时录制快得多；只有下载被站点拦掉时才会自动退成边播边录。
