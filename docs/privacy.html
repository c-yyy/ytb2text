视频转文字助手 · 隐私政策

最后更新：2026-09-11

一句话总结：音频与模型全部在你的本机浏览器里处理， 不上传任何音频，不需要 API Key，也不收集、不上报任何使用数据。

1. 插件处理了什么数据

  • 音频数据：来自你选择的音频来源（录制当前标签页的声音 / 你挑选的本地音视频文件 / 页面内视频的媒体直链）。音频在浏览器进程内被解码为 16kHz 单声道 PCM，然后交给本地的 Whisper 模型做语音识别。 音频不会被发送到任何服务器。
  • 转录结果：文字结果只保留在当前页面内与扩展的本地存储 （chrome.storage.local）中，用于刷新页面后恢复上次结果。 只有在你主动点击「复制 / TXT / SRT / VTT」时，内容才会离开扩展。
  • 设置项：模型、语言、运行设备、下载源等偏好保存在本地。

2. 插件会发起哪些网络请求

  • 下载模型权重：首次使用某个模型时，会从你选择的下载源 （默认 hf-mirror.com，可切换为 huggingface.co） 拉取 ONNX 权重文件，随后由浏览器缓存。请求中不包含你的音频， 只是普通的文件下载。
  • 抓取你指定的媒体：当你选择「页面内视频」并点击转录时， 插件会按该媒体在页面上的直链地址下载文件（与你在页面上播放时访问的是同一个地址）。
  • 读取页面自带字幕：当你点击「直接取字幕」时， 插件会请求该页面已公开的字幕地址。

除此之外，插件不发起任何网络请求；不含统计、埋点、广告或崩溃上报 SDK。

3. 权限用途

  • tabCapture：录制你主动点击「录制当前标签页」时的标签页声音。
  • offscreen：在后台文档里运行录音与模型推理。
  • storage / unlimitedStorage：保存设置与模型缓存。
  • scripting / activeTab：注入页面内面板、读取页面已公开的字幕轨。
  • host_permissions：下载模型权重，以及按你指定的地址下载页面内媒体。

4. 数据共享

不共享。插件没有后端服务，开发者无法访问你的音频、转录文本或任何使用记录。

5. 第三方组件

  • Transformers.js 与 ONNX Runtime Web —— 本地推理运行时（已随扩展打包，不从 CDN 加载）。
  • Whisper 模型权重 —— 由 OpenAI 发布，经 HuggingFace 分发；下载来源可在设置中切换。

6. 你的控制权

  • 随时卸载扩展即可停止全部处理，并清空本地保存的设置与结果。
  • 模型缓存位于浏览器的 Cache Storage，可通过 Chrome 的「清除浏览数据」删除。
  • 不录制、不转录时，插件不会访问任何音频。
